Undergraduate Programs

Bachelor's degrees

The college currently offers two programs, with more planned. Each combines strong foundations with hands-on practice.

BS Information Technology (BSIT)

Bachelor of Science in Information Technology

Program Description

Focuses on the rigorous training of students with the latest IT concepts and applications.

PAASCU Level 2

Curriculum Overview

CoreNetworking, database systems, information assurance and security, system administration
TracksNetwork Technology or Software Technology
ElectivesWeb systems and related areas
CapstoneCapstone project and practicum

Career Paths

Database AdministratorIT EntrepreneurInformation Security AdministratorIT InstructorProgrammerTechnical Support SpecialistWeb Developer / AdministratorResearcherTrainer

BS Computer Science (BSCS)

Bachelor of Science in Computer Science

Program Description

Prepares students to be highly competent and certified in the areas of computing theory and applications.

PAASCU Level 1

Curriculum Overview

CoreProgramming, data structures, algorithms, software engineering, operating systems
TracksRobotics, or Mobile and Game Development
ElectivesSpecialization electives for Intelligent Systems and Game Development

Career Paths

Applications DeveloperCS InstructorResearcherTrainerDatabase Programmer / DesignerMobile Applications DeveloperGames DeveloperSystems Analyst
